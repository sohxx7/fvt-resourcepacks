# FvT Minecraft 26.3 Resource Packs

Resource packs for the local FvT server port to Minecraft Java 26.3 (resource format 97.1).

Original project: https://github.com/heIp12/fate-vs-touhou-Server/releases/tag/v1.0.0

Apply the packs in this order: `base.zip`, `Touhou_Holy_Grail_War_sub_1.zip`, `Touhou_Holy_Grail_War_sub_2.zip`.

The base pack includes assets generated by BetterModel 3.5.1. Textures, models, fonts, and sounds originate from the original project and its bundled resources; their rights remain with their respective creators. This is an unofficial compatibility conversion, not a claim of original authorship.

The original transparency post shader was adapted to the final scene blit in 26.3. Separate translucent layers and scene depth are unavailable at that stage, so depth-sensitive screen effects use a fixed near-field fallback and do not have full visual parity. Real-client GPU/audio behavior has not been verified. Thirteen model/texture references were already unresolved in the original packs.

See `manifest.json` for SHA-1/SHA-256 checksums. These public release URLs can be downloaded by Minecraft clients without GitHub authentication.
